title: New screens use Jetpack Compose
scope: android
mode: advisory
status: example
---

A new screen is built with Jetpack Compose. Existing XML layouts stay as they are until someone changes them for another reason.

## Why

One way to build new screens keeps the UI code consistent.

## How to check

A new screen adds composable functions. It does not add a new layout XML file or a new Fragment with view binding.
