---
id: AND-004
title: Text a user sees comes from string resources
scope: android
mode: advisory
status: example
---

Text that a user can see or hear comes from a string resource, not from a literal in the code. This includes content descriptions.

## Why

A literal in the code cannot be translated, and it is missed when wording is reviewed.

## How to check

A new user-facing string has an entry in `strings.xml` and is read with `stringResource` or `getString`. A literal is fine for log lines and identifiers.
