id: COM-001
title: A pull request says what was tested
scope: company
mode: advisory
status: example
---

The description of a pull request states what was tested and how: the automated tests that ran, and what was tried by hand.

## Why

A reviewer cannot tell a tested change from an untested one by reading the diff.

## How to check

The pull request description has a "Tested" part that names real checks. "Works on my machine" is not a check.
