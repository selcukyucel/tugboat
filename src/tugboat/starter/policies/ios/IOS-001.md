id: IOS-001
title: New unit tests use Swift Testing
scope: ios
mode: advisory
status: example
---

New unit tests are written with Swift Testing. Existing XCTest files stay as they are until someone changes them for another reason.

## Why

One test style in new code keeps tests easy to read and to review.

## How to check

A new test file imports `Testing` and uses `@Test`. It does not add a new `XCTestCase` subclass.
