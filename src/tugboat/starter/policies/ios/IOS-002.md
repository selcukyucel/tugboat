id: IOS-002
title: New screens use SwiftUI
scope: ios
mode: advisory
status: example
---

A new screen is built with SwiftUI. Existing UIKit screens stay as they are until someone changes them for another reason.

## Why

One way to build new screens keeps the UI code consistent.

## How to check

A new screen adds a SwiftUI `View`. It does not add a new `UIViewController` subclass, a storyboard, or a xib.
