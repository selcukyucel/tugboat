---
id: IOS-003
title: No force unwrap in app code
scope: ios
mode: advisory
status: example
---

App code does not use `!` to unwrap an optional, `try!`, or `as!`. A value that can be missing is handled where it is read. Test code may use them.

## Why

A forced unwrap turns a missing value into a crash on the user's phone.

## How to check

The changed app files add no forced unwrap, no `try!`, and no `as!`. An implicitly unwrapped property is new only where a framework demands it.
