---
id: IOS-004
title: Text a user sees is localised
scope: ios
mode: advisory
status: example
---

Text that a user can see or hear comes from the string catalog, not from a literal in the code. This includes accessibility labels.

## Why

A literal in the code cannot be translated, and it is missed when wording is reviewed.

## How to check

A new user-facing string has an entry in the string catalog and is read through it. A literal is fine for log lines and identifiers.
